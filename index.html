WeatherGPT

A conversational weather platform for India that never makes up a number.

Context
Smart India Hackathon 2026, problem SIH26068. Cleared the internal college round.
Languages
English, Hindi, Hinglish and Marathi, typed or spoken.

Source on GitHub

Screenshots from the project repo. They show its mocked test data.

Problem
Ask a language model about the weather and it will happily invent a forecast.
Pipeline
Live Open-Meteo and NOAA GFS data is validated with Pydantic into structured facts. Replies come from templates in four languages. An optional LLM may reword them, and its numbers are checked against the facts.
Architecture
A Next.js PWA (chat, dashboard, map, alerts, climate, risk board) on a FastAPI backend with a query parser and one threshold-driven alert engine. Supabase handles sign-in and push subscriptions.
Built with
Next.js, TypeScript, Tailwind, MapLibre GL, deck.gl, Leaflet, FastAPI, Pydantic v2, HTTPX, Supabase
Result
The query parser gets every field right on 91.7% of a held-out set of 24 questions across the four languages, up from 41.7% before tuning.

EchoPanel

Live AI voice interviews with a panel of three.

Flow
Apply with a CV, get shortlisted, join by a one-time link, talk to the panel.
Status
Tested end to end and presented live on 30 October 2026.

Source on GitHub

Screenshots from the project repo. Nexora Labs and its candidates are fictional demo data.

The panel
Technical, Product and Behavioural interviewers take turns. After each answer a Moderator decides who speaks next.
Assessment
The transcript is scored on five dimensions. Every evidence quote in the report must match something the candidate actually said, or the output is rejected and retried.
Architecture
A Next.js app on PostgreSQL with Prisma. Separate workers handle CV virus scanning, email and assessment. Voice runs over Agora and the assessment on Groq.
Built with
Next.js 14, React 18, TypeScript, Tailwind, PostgreSQL, Prisma, Better Auth, Agora RTC, Groq, Resend, ClamAV, Vitest, Playwright
Result
318 automated tests pass. No hiring decision is automated: the report is there for a person to review.

LocalBiz Connect

Influencer campaigns a local business can actually measure.

Problem
A shop pays an influencer and then has no clear way to tell what the campaign brought in.

Source on GitHub

Captured by running the repo locally without its database, so data views are empty and fonts may differ.

Approach
A business creates a campaign with unique discount codes. Influencers share their code, and each redemption at checkout is attributed back to the campaign and the creator.

Built with

EV adoption forecasting

Forecasting electric vehicle adoption, county by county, three years ahead.

Context
Built during an AICTE internship (cycle 2).
Why
Planners need to know where charging capacity will be needed before the demand arrives.

Source on GitHub

Captured by running the Streamlit app from the repo with its trained model.

Data
About 20,800 rows of county-level EV registration data, cleaned, with outliers capped.
Features
EV totals from the previous one, two and three months, a three-month rolling mean, percentage changes and a six-month growth slope.
Model
A Random Forest regressor tuned with randomized search over 30 candidates and 3-fold cross-validation.
App
A Streamlit app to view one county’s forecast and expected growth, and to compare up to three counties.
Built with
Python, pandas, NumPy, scikit-learn, Matplotlib, Seaborn, Streamlit, Jupyter

How I work

  • Ground it

    The data decides and the model explains. In WeatherGPT the language model only talks about facts that were verified first.

  • Show the evidence

    An AI judgement should point at what it’s based on. EchoPanel’s reports tie every point back to the interview.

  • Build the whole thing

    I take a product from database and API to the screen and the deploy, so nothing is left as someone else’s problem.

  • Measure what it did

    A feature should be able to prove it worked. LocalBiz Connect uses coupon codes so a business can see what a campaign returned.
